BsdxWorkshop — BSDX 機体・技 調整ツール
=================================================

■ 起動
  BsdxWorkshop.bat をダブルクリック。Java のインストールは不要です（runtime フォルダに同梱）。

■ 最初に
  1. 「ファイル → ゲームフォルダを開く」で、ゲームの exe と Dat.pac があるフォルダを選びます。
     ゲームのファイルは読み取り専用で開き、ゲームフォルダには一切書き込みません。
  2. MOD を調整するときは「ファイル → オーバーレイを開く」で MOD の Update3.pac を指定します。
  3. 調整したら「書き出し」。検証に通ったものだけ Update3.pac として書き出します。
     書き出し先の既定は、このフォルダの中の out フォルダです（設定で変えられます。このフォルダの外へは、設定で許可しない限り書き出しません）。
     ゲームへの反映（ゲームフォルダへ置く）はご自身で行ってください。元の Update3.pac は退避してから。

■ 画面
  使い方はツールの「ヘルプ → 使い方」（F1）にあります。
  項目名の * は、ゲームの exe に無い、このツールで付けた名前です。

■ 設定ファイル
  app\BsdxWorkshop.settings.properties（このフォルダの外には何も書きません）。

■ 注意
  このツールには、ゲームのリソースは含まれていません。
  利用は、各自の責任のもとで行ってください。
